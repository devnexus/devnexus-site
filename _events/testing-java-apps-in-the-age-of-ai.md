  write buggy code too! \r\n\r\nIn this session, you’ll learn techniques for improving
  tests for new and existing code and how to get ore thorough tests. You’ll see how
  to use tools like code coverage and mutation testing to see how thorough they are.
  You’ll also see examples of how to tell if the work is even correct. After all,
  having a regression test for an AI generated bug still leaves you with the bug."
