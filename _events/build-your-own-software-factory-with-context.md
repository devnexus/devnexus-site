title: Build your own software factory with context
description: "Coding agents made writing code cheap, yet everything around the code
  still lands on people: turning tickets into changes, reviewing them, keeping the
  repo healthy. A software factory hands that work to agents. What makes it trustworthy
  is context: the rules and skills that tell each agent how your team works.\r\n\r\nIn
  this hands-on workshop you'll set up a factory on a GitHub repo from your own coding
  agent. You'll label an issue and watch it become a pull request, teach the factory
  one of your team's rules, and add a loop that keeps the repo healthy. You'll leave
  with a factory you can point at your own repo the same week."
