title: Hands on Spring AI
description: "If you've never used Spring AI, this workshop is for you.\r\n\r\nWe'll
  spend the day working through the features of Spring AI, one at a time. For each
  one, you'll learn what it does and when to reach for it. Then you'll write a small
  demo of it yourself. This is very hands-on. You'll be coding for most of the day.\r\n\r\nWe
  start with what you need to get going:\r\n\r\nSetting up a project and talking to
  a model with ChatClient\r\nSwitching between OpenAI, Anthropic, and a local model\r\nPrompts,
  prompt templates, and chat memory\r\nStructured output that turns responses into
  Java records\r\nThen we move into the features real apps are built on:\r\n\r\nAdvisors,
  and how they shape every request and response\r\nTool calling, so the model can
  call your Java code\r\nRetrieval augmented generation (RAG) with your own documents\r\nMCP,
  from building servers to connecting clients\r\nAgents that plan and act on their
  own\r\nBy the end of the day, you'll have a folder full of working demos, a clear
  picture of how the parts of Spring AI fit together, and everything you need to build
  your first AI app on your own.\r\n\r\nYou should be comfortable with Java and Spring
  Boot. You don't need any AI experience.\r\n\r\nSetup: Java 21 or later, an IDE,
  and Docker. Setup instructions go out before the workshop."
