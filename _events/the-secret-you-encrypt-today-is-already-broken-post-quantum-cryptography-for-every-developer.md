title: 'The Secret You Encrypt Today Is Already Broken: Post-Quantum Cryptography
  for Every Developer'
description: "Somewhere, a machine is being built that computes by letting possibilities
  interfere with one another, and in 1994 Peter Shor showed that such a machine could
  unravel the RSA and elliptic-curve cryptography protecting almost every connection
  your code makes. That machine does not yet exist at scale. It does not need to.
  Adversaries are already harvesting encrypted traffic today in order to decrypt it
  tomorrow, which means that anything your application sends that must stay secret
  for a decade is, in a meaningful sense, already exposed.\r\n\r\nThis session takes
  quantum computing out of the physics lab and puts it into your pull requests. Starting
  from an intuitive, equation-light tour of why quantum computers break today's cryptography,
  it moves to the practical answer: post-quantum cryptography. Attendees will see
  the NIST standards ML-KEM and ML-DSA, the post-quantum APIs already available in
  the JDK, hybrid key exchange already running in modern TLS, and the crypto-agility
  patterns that let systems change algorithms without rewrites. Drawing on the EU
  Q-FENCE project and a portfolio of quantum computing patents, the session closes
  with a migration checklist: find your cryptography, rank it by secrecy lifetime,
  and start moving."
