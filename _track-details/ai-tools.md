The Building AI Applications & Agents track focuses on creating software that puts AI to work. Sessions explore model integration, retrieval-augmented generation, context engineering, multimodal applications, and agents that interact with tools, data, and other systems. Developers and architects will learn practical patterns for moving from an initial idea to working applications that solve real problems.
